# Mathlearnkelompok5

Analisis PRD MathLearn yang sudah saya berikan.

Saya ingin mengerjakan website secara bertahap. Untuk sekarang, fokus hanya pada Tahap 1 yaitu Fondasi dan Desain Website.

Buat rencana implementasi yang mencakup:

1. Struktur folder dan komponen website.

2. Header, navigasi, dan footer.

3. Sistem warna, tipografi, dan desain UI.

4. Struktur tujuh halaman dengan placeholder sederhana.

5. Sistem navigasi antarhalaman.

6. Responsivitas desktop dan mobile.

7. Checklist pengujian Tahap 1.

Batasan:

- Jangan mengerjakan fitur materi, kalkulator, kuis, atau video.

- Jangan membuat database atau autentikasi.

- Jangan menambahkan fitur di luar Tahap 1.

- Pertahankan teknologi dan struktur yang sesuai untuk proyek ini.

Penting: Jangan menulis atau mengubah kode. Saya hanya ingin melihat rencana pengerjaannya terlebih dahulu untuk diperiksa.
